# TechMitra

Cinematic website for TechMitra — Technology That Moves Nepal Forward.

## Quick start

```bash
cd web
npm install
npm run dev
```

Open http://localhost:5173

## Project layout

- `web/` — React + Vite application
- `design-system/techmitra/` — UI UX Pro Max design system
- `.cursor/skills/ui-ux-pro-max/` — design skill database

## Narrative

Everest → Nepal → Wonders → Digital Nepal → TechMitra → Technology → Products → Global → Everest
