# TechMitra Website

Cinematic scroll-driven experience for TechMitra — Technology That Moves Nepal Forward.

## Stack

- React + Vite
- Tailwind CSS v4
- Three.js / React Three Fiber / Drei
- GSAP ScrollTrigger
- Anime.js
- Lenis

## Develop

```bash
cd web
npm install
npm run dev
```

## Build

```bash
cd web
npm run build
npm run preview
```

## Narrative

Everest → Nepal → Wonders → Digital Nepal → TechMitra → Technology → Products → Global → Everest
